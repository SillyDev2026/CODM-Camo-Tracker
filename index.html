Settings & backups

PLAYER PROFILES

Profiles are separate on this device. Create one for each CODM player.

Starter import includes Cordite, QQ9, CBR4, Switchblade X9, OTs 9 and TEC-9. It does not clear any existing progress.

LOCAL BACKUPS

Your data is automatically saved in IndexedDB. Download a JSON file as a portable backup or import one on another device.

Local browser storage is not a guaranteed permanent backup. Keep an exported file somewhere safe.

GITHUB REPOSITORY BACKUP ADVANCED

Save the current player profile to a private GitHub repository you own. This works without our own backend, but requires a fine-grained token with Contents: Read and write permission for that one repository.

The token is never written to local storage, uploaded to this site, or included in exported backups. Do not use a broad-scope classic token. This is not a GitHub sign-in.

Before restoring on another device, import an exported profile or full JSON backup to preserve its unique profile ID. Never store secrets in a public repository.
