CONTROL PANEL

Settings & backups

PLAYER PROFILES

Profiles track Multiplayer and Zombies camos separately. Create one for each CODM player.

Starter import includes Cordite, QQ9, CBR4, Switchblade X9, OTs 9 and TEC-9. It does not clear any existing progress.

LOCAL BACKUPS

Your data is automatically saved in IndexedDB. Download a JSON file as a portable backup or import one on another device.

Local browser storage is not a guaranteed permanent backup. Keep an exported file somewhere safe.

GITHUB REPOSITORY BACKUP ADVANCED

Save the current player profile to a private GitHub repository you own. This works without our own backend, but requires a fine-grained token with Contents: Read and write permission for that one repository.

The token is never committed to GitHub or included in exported backups. Optional device storage uses password-protected encryption. Do not use a broad-scope classic token. This is not a GitHub sign-in.

ENCRYPTED TOKEN VAULT ON THIS DEVICE

Remember this token between visits without storing it in plaintext. Choose a separate vault password (12+ characters), then enter it again next time to unlock the token. No server or GitHub secret upload is involved.

Checking for saved token…

If you forget the vault password, remove the saved token and enter a new PAT. Clearing browser site data removes the encrypted copy. The vault does not sync across devices.

Before restoring on another device, import an exported profile or full JSON backup to preserve its unique profile ID. Never store secrets in a public repository.
ABOUT

Weapon-only tracker for ARs, SMGs, LMGs, snipers, marksman rifles, shotguns, pistols, melee weapons and launchers. It does not track tacticals, lethals, perks, operator skills or scorestreaks. Unlocks are manually recorded, not verified by Activision. Rosters and requirements can change.
